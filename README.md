# Tikhonov-Vladimir-Project-3
Project 3. Web
----------------------------------------------------------------------------------------------------------------------------------------------------
Программа показывает историю курса трёх валют - евро, доллара и юаня. После запуска программы Table.py, на экран выведется график курсов этих валют.
Программа состоит из нескольких частей - Scraper.py, который является основой, которую использует Lost.py на сайте ЦБ России, собирая данные с страниц сегодняшних курсов трёх валют.
После сбора, программа берёт уже сохранённую информацию о предыдущих днях из файла History.txt и загружает её, после чего добавляет сегодняшний курс к уже существующей истории и обновляет файл с ней.
После этого, Table.py строит график обновлённого курса.
Для запуска программы, достаточно иметь в папке 4 файла - Scraper.py, Lost.py, Table.py и History.txt, и запускать необходимо только Table.py.
